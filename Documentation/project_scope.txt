RANSOMWARE READINESS AND OUTLOOK PHISHING INDICATOR SCANNER 
===========================================================

PROJECT SCOPE
-------------

This project builds a defensive PowerShell-based scanner that reviews a Windows endpoint for ransomware readiness, phishing-related risk indicators, endpoint protection status , suspicious file indicators, startup and persistence locations, backup and recovery readiness, and Outlook/email phishing indicators. 

The scanner is designed for a personal Windows lab environment first, using safe test data. It may also include an optional Outlook Desktop read-only mailbox scan module that inspects local Outlook email properties for phishing indicators without modifying messages.

The project does NOT use or do the following: use malware, encrypt files, open attachments, click links, delete emails, move emails, send emails, and does not interact with company systems without authorization. 

The purpose of this project is to demonstrate how ransomware readiness can be reviewed from multiple defensive angles: 

1. Endpoint protection status 
2. Windows Defender and Windows Security settings 
3. Optional Sophos detection
4. Firewall status 
5. Windows Update and patch readiness
6. Suspicious ransomware-style file indicators 
7. Outlook and email phishing indicators 
8. Suspicious links, attachments, senders, and keywords
9. Startup and persistence review 
10. Backup and recovery readiness
11. User account security 
12. Risk scoring 
13. Automated TXT and CSV reporting 

This project was inspired by the real-world risk of ransomware incidents that begin through phishing . The scanner connects phishing indicators with ransomware-readiness checks to show how email security, endpoint protection, backups, and system hardening all work together as part of ransomware defense. 

PROJECT SAFETY BOUNDARIES
-------------------------

This project will not perform offensive security activity.

The scanner will NOT:

- Create malware
- Run malware
- Encrypt files
- Delete files
- Modify user files
- Open email attachments 
- Click links
- Download files from links 
- Harvest credentials 
- Scan networks 
- Attack systems 
- Delete emails 
- Move emails 
- Mark emails as read or unread intentionally
- Reply to emails 
- Forward emails 
- Send emails 
- Access company mailboxes without approval 
- Connect to any work systems without approval

The scanner will only:

- Read local Windows security settings 
- Read selected safe test folders 
- Review fake/sample email data
- Optionally inspect local Outlook Desktop mailbox items in read-only mode
- Extract links as plain text only 
- Review attachment names and extensions only 
- Check local services and security posture 
- Generate TXT and CSV reports 
- Create findings and recommendations 

OUTLOOK AND EMAIL PHISHING ANALYSIS
-----------------------------------

The scanner will include an Outlook and email phishing indicator module.

The project will start with safe sample email data and may later include an optional Outlook Desktop read-only mailbox scan. 

The email scan will look for:

- Suspicious sender domains 
- Sender display name and sender email mismatch 
- Reply-To and Return-Path mismatch, where available 
- Risky attachment extensions 
- Compressed attachments 
- Macro-enabled Office attachments 
- Script or executable attachments 
- HTTP links 
- Shortened URLs
- IP-address-based links 
- Very long URLs
- Multiple links
- Suspicious login, account, payroll, invoice, payment, document-share, or password-reset wording
- Ransomware-related keywords 
- Authentication header indicators such as SPF, DKIM, and DMARC results if available 

The scanner will not open attachments, click links, download files, send email, delete email, or interact with real organizational mailboxes unless explicitly approved.

SUSPICIOUS LINK DETECTION
-------------------------

The scanner will inspect links as plain text only.

Suspicious link indicators may include:

- HTTP instead of HTTPS
- URL shorteners
- Links containing IP addresses 
- Very long URLs
- Encoded characters
- Multiple links in one message 
- Login or password-reset keywords
- Invoice, payroll, payment, account, or document-share keywords
- Domains that appear to impersonate trusted services

The scanner will not visit or test links online by default. This avoids sending potentially sensitive URLs to external services.

OPTIONAL SOPHOS DETECTION
-------------------------

The scanner will include optional Sophos detection logic.

If Sophos is installed, the scanner will attempt to detect Sophos-related services, processes, or installed application entries.

If Sophos is not installed, the scanner will record Sophos as not detected and continue the scan. 

Sophos detection is included because some organizations use Sophos alongside Windows Defender or Windows Security controls. This project does not connect to a Sophos console or use any real organizational Sophos data.
